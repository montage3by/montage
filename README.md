# montage

Монтаж и создание роликов с Claude Code.

## Скиллы (`.claude/skills/`)

| Скилл | Для чего |
|---|---|
| `video-script` | Сценарий ролика: хук, структура, раскадровка, тайминг, закадр |
| `speechwriting` | Тексты для голоса: речи, озвучка, суфлёр, расчёт длительности |
| `copywriting-ru` | Подписи, описания, заголовки, обложки, реклама, A/B-варианты |
| `edit-plan` | Монтажный лист: отбор дублей, тайм-коды, звук, титры, экспорт |
| `motion-promo` | Вертикальный промо-ролик с моушн-графикой в Remotion |

Скиллы подключаются автоматически по задаче или вручную: `/video-script`, `/motion-promo` и т.д.
