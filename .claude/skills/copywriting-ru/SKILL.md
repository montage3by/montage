# Копирайтинг

Хороший текст — это ясная мысль для конкретного человека, который должен сделать конкретное действие.

## 1. Бриф

Выясни (или допусти и перечисли допущения):

- **Продукт/тема** и что в нём реально отличается от альтернатив.
- **Аудитория**: кто, что болит, чего хочет, какие возражения, на каком языке говорит (слова из отзывов и комментариев — лучший источник).
- **Площадка и формат**: подпись Reels/TikTok, описание YouTube, пост, рекламное объявление, лендинг, email, карточка товара.
- **Цель и CTA**: одно действие.
- **Тон голоса бренда** — если есть примеры прошлых текстов, ориентируйся на них.
- **Факты и доказательства**: цифры, кейсы, отзывы. **Не выдумывай** цифры, отзывы и результаты — ставь плейсхолдер `[ЦИФРА: …]`, `[ОТЗЫВ: …]`.

## 2. Формулы (выбери подходящую, назови её)

- **AIDA** — внимание → интерес → желание → действие. Универсальна для рекламы и постов.
- **PAS** — проблема → усиление → решение. Для «болевых» продуктов.
- **BAB** — до → после → мост (продукт). Для трансформаций.
- **4U** для заголовков — полезный, ультраспецифичный, уникальный, срочный.
- **FAB** — свойство → преимущество → выгода. Для описаний товаров.
- **Сторителлинг** — герой, препятствие, решение, результат.

## 3. Правила

- **Выгода, а не свойство**: «монтируете ролик за вечер», а не «удобный интерфейс».
- **Конкретика**: цифры, сроки, примеры. Убирай «качественный», «уникальный», «лучший», «широкий спектр».
- **Пиши для одного человека** на «ты» или «вы» — по тону бренда, без смешивания.
- **Короче**: вычеркни всё, без чего смысл не меняется. Без канцелярита и воды.
- **Первая строка решает**: в подписях соцсетей видно 1–2 строки до «ещё» — там должен быть крючок.
- **Один текст — один CTA**.
- **Работа с возражениями**: закрой 1–2 главных прямо в тексте.
- **Честность**: никаких гарантий и обещаний, которых продукт не даёт; соблюдай законы о рекламе (маркировка, медицинские и финансовые обещания и т.п.).

## 4. Форматы и ограничения

| Формат | Ориентиры |
|---|---|
| Подпись Reels/TikTok/Shorts | Крючок в 1-й строке, 1–5 коротких абзацев, CTA, 3–7 релевантных хэштегов |
| Описание YouTube | Первые 2 строки с ключевыми словами и пользой, затем таймкоды, ссылки, CTA |
| Заголовок / текст на обложку | 3–6 слов, крупно читаемо на телефоне, интрига или выгода |
| Рекламный креатив | Заголовок + 1–3 предложения + CTA; учитывай лимиты площадки |
| Карточка товара | Выгода в заголовке, FAB-список, характеристики, ответ на главное возражение |
| Email | Тема (до ~50 знаков) + прехедер + короткое тело + одна кнопка |
| Лендинг | Оффер-заголовок, подзаголовок, выгоды, доказательства, возражения/FAQ, CTA |

## 5. Формат выдачи

1. Короткая шапка: аудитория, цель, формула, допущения.
2. **Основной вариант** текста.
3. **2–3 альтернативы** для A/B-теста, отличающиеся подходом (не синонимами): например, рациональный / эмоциональный / провокационный.
4. Для соцсетей — также 3–5 вариантов первой строки и текста на обложку.
5. Список плейсхолдеров, которые нужно заполнить реальными данными.

## 6. Проверка

- Понятно ли за 3 секунды, что предлагают и кому?
- Есть ли конкретная выгода и доказательство?
- Нет ли выдуманных фактов?
- Один ли CTA и понятен ли он?
- Звучит ли как человек, а не как нейросеть? Для финальной чистки — скилл `humanizer`.

Связанные скиллы: `video-script` — для самого ролика; `speechwriting` — если текст будет произноситься вслух.
