# Моушн-промо в Remotion

Шаблон промпта (источник: пост @chiko_dima, короткая версия). Перед работой заполни поля `<…>` из запроса пользователя; чего не хватает — спроси одним сообщением или выведи из проекта и явно перечисли допущения. Если доступен плагин Remotion — используй его скиллы (`remotion-create`, `remotion-best-practices`, `remotion-render`).

## Промпт

Ты — моушн-дизайнер мирового уровня, и этот ролик — твой шоурил. Покажи всё, на что способен. Go all out. Go crazy.

Сделай в Remotion вертикальный промо-ролик (1080×1920, `<длительность>` сек) про `<название продукта>`.

Проект лежит в `<путь к проекту>`. Изучи его: что это, для кого, фирменные цвета, логотип.

- Что это: `<одно предложение>`
- Для кого: `<аудитория и её боль>`
- Где доступен: `<платформы>`
- Призыв в конце: `<CTA>`
- Сценарий: `<твой текст тут, или «напиши сам: боль → поворот → решение → CTA»>`

Дизайн придумай сам, ни на что не опирайся: свобода полная. Скрины, референсы и мокапы бери из проекта или делай сам.

С первой секунды сильный хук. Дальше разные техники: типографика, игра форм, движения камеры, смены цвета.

В конце чистый запоминающийся кадр. Текст на русском, крупный, не заходит на интерфейс Reels сверху и снизу.

Найди крутой трек без проблем с авторскими правами (`<источник, например Mixkit>`) и звуки, если нужны.

Монтаж должен ощущаться нарезанным под музыку.

После рендера проверь ключевые кадры сам и поправь, что не так.

На выходе MP4 и README с источниками музыки.

Go all out, удиви.

## Как выполнять

1. **Бриф** — заполни поля шаблона. Сценарий, если не дан, пиши по скиллу `video-script` (боль → поворот → решение → CTA), подпись к посту — по `copywriting-ru`.
2. **Музыка** — только треки с лицензией, разрешающей коммерческое использование (Mixkit, Pixabay Music, YouTube Audio Library и т.п.). Запиши в README: название, автора, ссылку, лицензию. Определи BPM и расставь сетку битов — смены сцен и акценты ставь на доли.
3. **Сборка** — Remotion-проект в отдельной папке (например, `videos/<имя-ролика>/`), композиция 1080×1920, 30 fps. Безопасные зоны: важный текст не в верхних ~10% и нижних ~20% кадра и не у правого края.
4. **Рендер** — `npx remotion render`, проверь длительность и звук (`ffprobe`), громкость ≈ −14 LUFS.
5. **Проверка** — вытащи ключевые кадры (`ffmpeg -ss <t> -frames:v 1`), посмотри их, найди проблемы (текст обрезан, читается слишком быстро, не попадает в бит, заходит на интерфейс) и исправь, перерендерь.
6. **Выход** — MP4 + README (идея, структура по секундам, источники музыки и звуков). Тяжёлые файлы (`node_modules`, рендеры) не коммить в git без запроса — добавь в `.gitignore`.
