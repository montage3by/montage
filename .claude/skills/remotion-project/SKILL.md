# Remotion-проекты в этом репозитории

Общие приёмы Remotion (анимация, аудио, субтитры, 3D) — в скиллах плагина Remotion, если он подключён. Здесь — то, что относится к этому репозиторию и облачному контейнеру.

Скрипты: `.claude/skills/remotion-project/scripts/`.

## Новый проект

1. Скопируй ближайший по типу проект без `node_modules` и `out`:
   `rsync -a --exclude node_modules --exclude out videos/<образец>/ videos/<имя>/`.
   Затем поменяй `name` в `package.json`, композиции в `src/Root.tsx` и скрипт `render`.

   | Задача | Образец |
   |---|---|
   | Анимация логотипа или названия, 9:16 + 16:9 | `merlin-agency` |
   | Петля по картинке: фон, обложка, стрим | `kuro-loop` |
   | Петля по рендеру + текстовые слайды + логотип | `pool-ad` |
   | Оживление статичного кадра деформацией | `push-scene` |
   | Рилс с озвучкой, субтитрами и SFX | `tier-lincoln-lawyer` |

2. В корне проекта должен лежать `remotion.config.js`: он подставляет Chromium, предустановленный в облачном контейнере, а локально ничего не меняет. Формат — `.js`: `.ts`-конфиг требует `tsconfig.json`, которого в проектах нет.
3. 30 fps. Размеры: 1080×1920 (9:16), 1920×1080 (16:9), 1080×1350 (4:5), 1080×1080 (1:1).
4. Шрифты — только с открытой лицензией (Google Fonts, SIL OFL): `.ttf` и файл лицензии в `public/`. Платный шрифт — только когда клиент купил лицензию.
5. Всё, что нужно для рендера, лежит в `public/` и коммитится. Видео (`*.mp4`, `*.mov`) в git не попадает — для таких ассетов в README написано, откуда их взять и куда положить. Сгенерированный ассет (карта смещения, маска, текстура) коммить вместе со скриптом, которым он сделан: иначе проект не пересобрать.

## Рендер

- `npm install`, затем `npm run render` или `npx remotion render <Id> out/<имя>.mp4`. Ролик 6 с в 1080p рендерится ≈ 15–20 с.
- Черновик: `--scale=0.25` (масштаб должен давать целые размеры кадра; `0.33` падает) или `--frames=0-59`.
- Финал: `--crf=16`…`18`.

## Петли

Каждое движение повторяется с периодом, который делит длину петли нацело: `Math.sin(2 * Math.PI * k * frame / durationInFrames)` с целым `k`; частицы и смещения — по модулю длины петли; шум — по окружности в пространстве шума. Анимация, которая не возвращается в исходное состояние к последнему кадру, рвёт петлю.

Проверка: `scripts/loop-check.sh out/<петля>.mp4` сравнивает шов «последний кадр → первый» с самым резким переходом между соседними кадрами. `OK` — петля бесшовная. `SEAM` — найди движение, которое не замыкается. Для проверки хватает рендера с `--scale=0.25`.

## Проверка кадров

После каждого рендера:

1. `scripts/contact-sheet.sh out/<ролик>.mp4 <scratchpad>/sheet.png [cols] [rows]` и посмотри PNG через Read. Отдельный кадр: `ffmpeg -ss <t> -i out/<ролик>.mp4 -frames:v 1 <scratchpad>/f.png`.
2. Ищи:
   - текст обрезан или заходит в зоны интерфейса 9:16 (верхние ~10%, нижние ~20%, правый край);
   - текст на экране меньше, чем нужно на чтение: ≈ 3 слова в секунду + 0,5 с;
   - чёрные или пустые кадры, артефакты деформации, швы;
   - смены сцен мимо долей музыки.
3. `ffprobe -v error -show_entries format=duration:stream=width,height,r_frame_rate -of compact out/<ролик>.mp4`.

Готово, когда на контактном листе нет ни одной проблемы из списка, а размер, fps и длительность совпадают с заданными.

## Звук и сдача

- Музыка и SFX — с лицензией на коммерческое использование или синтезированные самим (ffmpeg, код). Источник и лицензия — в README проекта.
- Голос, субтитры, громкость −14 LUFS, сжатие под чат — по скиллу `ffmpeg-edit`.
- README проекта: идея, структура по секундам, команды, шрифты и лицензии, источники музыки и звука, что пользователь подкладывает сам.
- Коммить `src/`, `public/`, `package*.json`, `remotion.config.js`, README. Готовый MP4 — в чат (до 30 МБ) или на Google Drive.
