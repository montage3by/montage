# Merlin Agency — анимация названия

Remotion, 6 с, 30 fps. Две версии: `MerlinVertical` (1080×1920) и `MerlinHorizontal` (1920×1080).

Буквы поочерёдно выезжают из маски, позади вырастают фиолетовые овалы (по мотивам показа шрифта Scota), камера быстро «садится» и затем медленно наезжает, в конце появляется светлая линия.

## Шрифт

Unbounded Black — Google Fonts, лицензия SIL OFL 1.1 (`public/OFL.txt`), можно использовать коммерчески.
Референс — Scota (Limitype): бесплатная демо-версия только для личного использования; для клиента нужна платная лицензия. Если её купить, положите файл в `public/` и замените имя в `src/Merlin.tsx` (`FONT`, `Unbounded.ttf`).

## Музыка

Нет — ролик без звука.

## Команды

```
npm install
npm run studio   # превью
npm run render   # MP4 в out/
```
