# Тир-лист: «Линкольн для адвоката» (2011) — S-тир

Рилс 1080×1920, 50 с, 30 fps. Remotion.

Структура:
1. 0–6 с — отрывок из фильма (`public/clip.mp4`, ставится пользователем; пока заглушка), плашка серии и название.
2. 6–39 с — синопсис: озвучка + субтитры + крупные заголовки (решётка, «засекречено»).
3. 39–44 с — тир-лист: карточка фильма влетает в S, удар, штамп «S-ТИР».
4. 44–50 с — CTA: кнопка «Подписаться», тап, «Вы подписаны».

## Как вставить отрывок
1. Положить файл в `public/clip.mp4` (вертикальный или любой — обрежется по центру), ~6 с.
2. В `src/Root.tsx` поставить `hasClip: true`.
3. `npm run render`, затем нормализовать громкость:
   `ffmpeg -i out/lincoln-lawyer-tier.mp4 -c:v copy -af loudnorm=I=-14:TP=-1.5 -c:a aac -b:a 192k out/final.mp4`
С отрывком фон синопсиса тоже станет размытым кадром из фильма.

## Звук
- Озвучка — синтез Piper TTS, голос ru_RU-dmitri-medium (датасет CC0). Файлы `public/vo-1..10.wav`; длительности прописаны в `src/timeline.ts` (`VO_DUR`) — при замене озвучки обновить их.
- Музыка и эффекты синтезированы ffmpeg (дрон, тиканье, пульс, райзер, удар, вжух, поп) — без сторонних прав.
- Шрифты Montserrat и Playfair Display — SIL OFL.

## Текст озвучки
Микки Холлер — адвокат без офиса. Он ведёт дела прямо с заднего сиденья своего «Линкольна» и вытаскивает почти любого клиента. Однажды ему достаётся дело мечты. Богатый наследник из Беверли-Хиллз обвиняется в нападении на девушку и клянётся, что невиновен. Гонорар — огромный. Дело — простое. Но чем глубже Микки копает, тем яснее понимает: его клиент связан со старым делом, из-за которого невиновный человек сидит в тюрьме. А рассказать правду Микки не может — его связывает адвокатская тайна. Макконахи — в одной из лучших ролей. Напряжение — до последней сцены. Мой вердикт — [S-тир]. Подписывайся!
