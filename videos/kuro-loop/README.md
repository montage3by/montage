# Kuro Sessions Vol.14 — зацикленный фон

Анимированная обложка для YouTube-сборника lo-fi. Remotion, 1920×1080, 30 fps, бесшовная петля 12 с (`KuroLoop`).

Что движется: дождь, мерцание и «дыхание» неоновых вывесок (夜, ラーメン и 集中 иногда коротко гаснут), тёплый свет автомата и будки, пар от кофе и из люка, круги на лужах, блик на очках, лёгкое зерно и медленный наезд камеры. Все движения повторяются с периодом, кратным 360 кадрам, поэтому конец переходит в начало без стыка.

Иллюстрация: `public/kuro-vol14.jpg`. Для нового выпуска замените картинку; координаты вывесок, пара и луж заданы в `src/KuroLoop.tsx` в пикселях исходника 2000×1116 — их нужно подправить под новую сцену.

## Команды

```
npm install
npm run studio   # превью
npm run render   # out/kuro-vol14-loop.mp4
```

## Видео под длину сборника

Петля повторяется под аудио (`mix.mp3` — ваш сборник) без перекодирования видео:

```
ffmpeg -stream_loop -1 -i out/kuro-vol14-loop.mp4 -i mix.mp3 \
  -map 0:v -map 1:a -c:v copy -c:a aac -b:a 320k -shortest kuro-vol14-full.mp4
```

Обложка для YouTube: `ffmpeg -i public/kuro-vol14.jpg -vf "scale=1280:720:force_original_aspect_ratio=increase,crop=1280:720" -q:v 2 thumbnail.jpg`.
