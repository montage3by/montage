# Push scene — 5 с

Анимация кадра: рука толкает мальчика (три толчка, мальчик следует с небольшим запаздыванием), сверху по доскам шагают воины — на каждый шаг кадр вздрагивает, из щелей сыплется пыль, тень ноги перекрывает свет огня. Плюс мерцание огня в щелях, искры, медленный наезд камеры.

Движение руки и мальчика сделано плавной деформацией (feDisplacementMap) по картам `public/disp-arm.png` и `public/disp-boy.png` — без вырезания объектов, поэтому без швов. Тайминг шагов и толчков — `STEPS` и `SHOVES` в `src/PushScene.tsx`.

```
npm install
npm run render   # out/push-scene.mp4 (1920×1080, 30 fps, без звука)
```
