# Выжимка чата «Монтаж и создание роликов»

Документ для переноса контекста в новый чат или сессию. Всё сделанное лежит в этом репозитории: **montage3by/montage**, ветка `main`.

## Как начать новый чат

Откройте новую сессию Claude Code на репозитории `montage3by/montage` и напишите:

> Прочитай HANDOFF.md и продолжим работу.

Скиллы из `.claude/skills/` подхватятся сами.

### Открытые задачи

1. **tier-lincoln-lawyer**:
   - положить отрывок из фильма (5–7 с) в `public/clip.mp4`, в `src/Root.tsx` поставить `hasClip: true` и перерендерить;

2. **Kuro Sessions Vol.18**: генерация обложки с тем же ежом. Идея сцены «Last Train / 終電»: Kuro в пустом ночном вагоне. Ждёт привязки Weave к Figma (см. раздел 4).

4. **pool-ad**: можно перекрасить акценты в фирменный цвет Sunrock `#B98757`, сделать форматы 4:5 и 1:1 или добавить музыку.

## 3. Технические заметки

- **Remotion в облачной сессии.** Браузер для рендера указывается так: `--browser-executable=/opt/pw-browsers/chromium_headless_shell-1194/chrome-linux/headless_shell`.
- **Шрифты.** Используются только Google Fonts (SIL OFL), файлы лицензий лежат в `public/` проектов. Платные шрифты (например, Scota) для клиентов не используются без покупки лицензии.
- **Озвучка.** Piper TTS, голос `ru_RU-dmitri-medium` (датасет CC0). Звучит разборчиво, но роботизированно. Разборчивость проверялась распознаванием faster-whisper.
- **Музыка и SFX.** В тир-рилсе музыка синтезирована ffmpeg, поэтому прав сторонних авторов нет. С Mixkit скачать не удалось: список треков подгружается динамически.
- **Громкость.** Целевой уровень −14 LUFS: `ffmpeg … -af loudnorm=I=-14:TP=-1.5`.
- **Бесшовные петли.** Все движения сделаны с периодом, кратным длине петли. Проверка: PSNR кадров «последний → первый» ≈ PSNR соседних кадров.
- **Деформация без вырезания** (push-scene): `feDisplacementMap` по размытым картам смещения.
- **Отправка в чат.** Лимит 30 МБ на файл. Крупные ролики пережимаются до ~18 Мбит/с или выкладываются на Google Drive.
- **Видео в git не храним.** В `.gitignore` стоят `*.mp4`, `*.mov`, `*.png` и `node_modules/`. Исходники и готовые ролики передаются через Google Drive (подключён к чату) или прямо в чат. Для тяжёлого монтажа лучше Claude Code на своём компьютере.
- **Контейнер облачной сессии временный.** Всё, что нужно сохранить, коммитится в этот репозиторий.

## 4. Сервисы и доступы

- **GitHub**:
  - `montage3by/montage` — рабочий репозиторий для роликов;
  - `montage3by/private_label` — **клиентский**, его не трогаем. Там осталась ветка `claude/modest-goodall-2x1fu9` со старой копией скиллов, оставлена по решению пользователя.
- **Figma.** Генерация картинок (`generate_image`) платная, кредиты списываются с плана **Projects**. **Weave** (генерация по образцу, в том числе видео из картинки) не привязан к Figma-аккаунту: нужно привязать на app.weavy.ai → Settings → Profile под тем же аккаунтом, который подключён к чату.
- **Google Drive** подключён: через него передаются исходники видео.

## 5. Договорённости

- **Перед любой платной генерацией называть цену и ждать «да».**
- Клиентские репозитории не трогать. Проекты роликов кладём в `montage`.
- Тексты для клиентов не выдумывают факты (цены, сроки, отзывы): если данных нет, ставится заглушка.
- Отрывки фильмов с YouTube не скачиваются: это нарушает правила сервиса. Отрывок присылает пользователь.
- Готовые ролики отправляются файлом в чат или на Drive, исходный код коммитится сюда.
